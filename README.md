# 精进群工具箱（测试）

定时视频播放页：打开即待机，到点自动播放指定视频，**播完一遍自动停止**，全程不可手动控制。

- 每天早上 **5:30** 自动播放 视频1，播完即停
- 每天晚上 **20:00** 自动播放 视频2，播完即停
- 所有打开页面的人按同一时间表观看同一视频
- 页面底部备注反馈邮箱

在线地址：<https://shouyueliang.github.io/>

## 使用方法

1. 提前打开页面（手机/电脑/平板均可），**无需任何操作**；播放时段内任何时候打开都可以，会直接对齐到统一进度
2. 页面内嵌播放器，没在播放时显示下一场的时间
3. 到点自动在播放器中播放，播完一遍自动停止

**关于声音：** 页面会直接尝试有声自动播放。首次访问的设备可能被浏览器安全策略静音，此时画面上会有「开声音」提示，点一下画面即可。

## 修改播放时间 / 更换视频

### 方式一：后台管理页（推荐）

打开 **https://happyxueyu.github.io/admin.html**：

1. 首次使用先创建一个 GitHub「细粒度访问令牌」（页面里有分步说明，只需选本仓库、Contents 读写权限）
2. 粘贴令牌验证 → 页面会加载当前播放计划
3. 直接修改时间、名称、视频地址（每行一个视频，多行自动连续播放），可增删场次
4. 点「保存并发布」→ 1~2 分钟后全站生效

令牌只保存在你自己的浏览器里，其他人打开管理页也无法保存。

### 方式二：直接改文件

编辑仓库里的 `config.json`（播放页启动时优先读取它；读取失败则用 `js/app.js` 内置默认值）。

**内置视频限制：** 单文件 ≤ 100MB（GitHub 硬限制，建议 ≤ 50MB）。过大视频需先压缩（降低分辨率/码率）。

更新代码后推送即可生效（GitHub Pages 1~2 分钟自动构建）。

## 技术说明

- 纯静态单页，零依赖；视频分段放在站点里，边下边播，只从本站（GitHub Pages）加载，不切换线路
- 按访客本地时钟触发；播放时段内打开页面即对齐到统一进度（当前时间 − 开播时刻），播完一遍自然结束
- 同步以「不打断播放」为前提：落后不超过 12 秒不调整；落后较多时只在目标位置已经缓冲好时才前跳；
  落后超过 2 分钟（如长时间切后台）才直接跳到直播位置
- 网络卡住时在原地址换连接重连，判定看的是数据而不是固定秒数：一个字节都没收到（起播 6 秒、其余 12 秒），
  或下载速度不到播放所需的一半且持续 15 秒才重连；数据在正常到达时不会被打断
- PWA：可添加到手机/电脑桌面当 APP 用；打开过的页面，已加载过的资源可离线使用
- 声明了屏幕常亮（Wake Lock，视浏览器支持），降低到点时设备已休眠的概率

## 目录结构

```
index.html              单页（视频层 + 待机界面 + 底部备注）
css/style.css           样式
config.json             播放计划：场次时间、各段视频及时长
js/app.js               定时调度、直播同步、卡顿自愈
test-media/             分段视频：*-i0*（片头）、*-sNN*（正文条带）、*-e*（片尾）
icons/                  应用图标
manifest.json / sw.js   PWA 配置与离线缓存
```

片头、片尾文件名带 `b` 的是压缩版（约 340kbps，关键帧间隔 2 秒），时长、帧数与原文件一致。
不带 `b` 的同名旧文件暂时保留，供改版前已打开页面的人播完片尾，之后可以删除。
